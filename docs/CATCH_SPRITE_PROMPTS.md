# Catch Sprite Replacement Prompts

Use these for GPT 5.5 when replacing catch sprites that are too high-detail for the current game style.

Global requirements to include in every prompt:

```text
Create a 64x64 pixel art catch/item sprite for a cozy fishing RPG.
Style must match low-resolution retro pixel game assets: crisp edges, chunky readable pixels, limited palette, dark outline, simple shading, no painterly gradients, no high-definition detail, no semi-realistic rendering.
The sprite must be readable at 24x24 and 32x32 UI sizes.
True transparent background with alpha channel.
Do not create a checkerboard background.
Do not create a fake transparent grid.
Do not use white, gray, black, or colored background fill.
No text, no watermark, no cast shadow, no floor, no background props.
Center the subject with 6-10 px padding.
```
